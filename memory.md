# Suparade: shared memory

Decisions and gotchas, newest at the bottom. One line each: `YYYY-MM-DD: fact (why it matters)`. Append; don't rewrite old lines. If a line stops being true, add a new line that says so.

- 2026-10-03: Under Vercel Services with `/api/(.*)` routed to the FastAPI service, FastAPI sees the `/api` prefix. The first merge fixed it with `FastAPI(root_path="/api")`. The team layout's `app/main.py` doesn't have it yet (re-add it if the payments API goes behind `/api` again).
- 2026-10-03: The repo moved from Thomas's local merge (FastAPI in `backend/app/`) to the team layout (`app/` at the root, `backend/` = Gemini detector). Notes that say `backend/app/` are stale.
- 2026-10-04: Supabase Compute is hidden in the CLI. It needs version 2.119 or newer plus `SUPABASE_EXPERIMENTAL_COMPUTE=1`, or `[experimental] compute = true` in `supabase/config.toml`. There are no public docs; the details come from the CLI binary. The Homebrew CLI (2.90) doesn't have it, so use `npx supabase@latest`.
- 2026-10-04: Compute has two sizes, 2gb (1 vCPU) and 4gb (2 vCPU). `instances` can be 0. Every deploy sends the full spec, so keep `size`, `exposure` and `instances` in `config.toml` or the next deploy resets them.
- 2026-10-04: The project signs user JWTs with an asymmetric ES256 key. `SUPABASE_JWT_KEY` in `.env` is that key's ID (`kid`), which is public in `https://pvoesovsparqqzosgwki.supabase.co/auth/v1/.well-known/jwks.json`. It's not a secret, and verifying tokens needs no secret: fetch the JWKS and match the token header's `kid`. `app/auth.py` currently checks tokens with `auth.get_user()`, a network call per request.
- 2026-10-04: The repo root `.env` is sourced by `run_e2e.sh`, so every line must be `KEY=value` or start with `#`. A bare `Supabase` line ran the Supabase CLI (macOS paths are case-insensitive) and hung the shell; values with spaces need quotes.
- 2026-10-04: Plain `pytest` also collected `backend/tests`, whose import of `backend/config.py` loads the real `.env`, so the payments tests' dummy `AGENT_API_KEY` lost and 6 tests got 401. `pytest.ini` now limits pytest to `tests/`; run the detector suite with unittest.
- 2026-10-04: Stripe transfers are paid from the platform's Stripe balance, not the campaign budget in Supabase. With the budget funded but the test balance at $3.96, a $4.50 tip failed with "insufficient available funds". `run_e2e.sh` now adds test funds (`stripe_check --add-test-funds`) when available is under $10.
- 2026-10-04: `scripts/run_e2e.sh` was committed without the executable bit (`./scripts/run_e2e.sh` gave "permission denied"); fixed with chmod +x.
- 2026-10-04: Evidence (thumbnails, clips, alert audio and cards) lives on the detector's disk under `backend/evidence/`. Tips in Supabase keep those relative paths in `detections.meta`, so on another machine they 404; the portal hides missing frames.
- 2026-10-04: The detector's WebSocket replays only live sessions and recent chat on connect, not clip statuses; `GET /api/events` returns the last 200 events. After a full reload the portal's clip bars start empty.
- 2026-10-04: The other team project's video reader (whole mp4 with audio to Gemini, structured output, CDN links from the listing instead of yt-dlp) was reviewed for the detector. The detector already sends whole 10 s clips with audio and a forced schema; live streams have no CDN link, so streamlink + ffmpeg stays.
- 2026-10-04: `FastAPI(root_path="/api")` is back in `app/main.py`, with a test for `/api/health`. The 2026-10-03 line saying it was missing is resolved.
- 2026-10-04: Supabase has three look-alike credentials. The `sb_publishable_…` API key is safe in the browser (works with RLS). The `sb_secret_…` API key is server only. The personal access token `sbp_…` (Account → Access Tokens) is the only one the CLI and the Management/Compute API accept. Putting a publishable key in `SUPABASE_ACCESS_TOKEN` gets "Invalid access token format".
- 2026-10-04: Compute smoke test results.
  - Public Compute URLs have no auth layer: anyone with the URL (`<ref>.supabase.co/compute/v1/<name>`) reaches the app, so the app must check its own key.
  - The path prefix is stripped before the request reaches the app, and WebSockets pass through.
  - Every container gets the project's Edge Function secrets as env vars, including `SUPABASE_SERVICE_ROLE_KEY` and `SUPABASE_DB_URL`.
- 2026-10-04: The `sbp_` token in `.env` can deploy and delete Compute but not set secrets ("Missing required permission(s): edge_functions_secrets_write"). Secrets need an account or token with that permission.
- 2026-10-04: `STRIPE_WEBHOOK_SECRET` in the local `.env` is the Stripe CLI listener secret for this account (`stripe listen --api-key $STRIPE_SECRET_KEY --print-secret` matches it). The test account has no dashboard webhook endpoints, so local funding tests need `stripe listen --forward-to localhost:8001/webhooks/stripe`; a deploy needs its own endpoint and secret.
- 2026-10-04: Checkout success and cancel URLs pointed at `/campaigns/<id>`, which the portal doesn't have; they now go to `/?funded=1|0` (Mission control).
- 2026-10-04: The detector accepts a local file path as a session url, and `/api/sessions/{id}/media` serves that file. On a public URL, anyone who can create a session could read `/proc/self/environ`, which holds the service role key. That's why `X-Detector-Key` (`DETECTOR_KEY`) guards every endpoint that creates or changes a session; `backend/tests/test_detector_key.py` covers it. Keep the key out of `NEXT_PUBLIC_` vars: a browser-held key is public.
- 2026-10-04: The demo clip (`backend/demo/demo_stream.mp4`) gets every brand moment blocked as `looks_staged`, locally and on Compute; demo mode only adds alerts. On that clip only `sponsor_screen_time` pays (38¢ on 2026-10-04). To show a verified tip, use a real stream (the clips in `demo/test_media/` haven't been checked).
- 2026-10-04: All three migrations are applied on the hosted project, but under other version numbers (`20261003191542_suparade_init`, and so on; applied through the SQL editor or MCP) than the local files (`20261003000000_init.sql`, and so on). `supabase db push` would try to run them again. Run `supabase migration repair` first, or keep applying new migrations the same way.
- 2026-10-04: The security advisor flags `public.rls_auto_enable()` (SECURITY DEFINER, callable by anon over `/rpc`). It isn't from our migrations, and it returns `event_trigger`, so Postgres refuses a direct call. Low risk; `revoke execute ... from anon, authenticated` silences it.
- 2026-10-04: The portal's key route (`frontend/app/detector/sessions/`) adds `DETECTOR_KEY` for any visitor, so the key no longer separates trusted callers from strangers. This briefly let anyone read files in the detector container through `/media`. It was confirmed with `/etc/hostname`; the logs show no other use. The fix is that `create_session` only accepts local files inside `backend/demo/`. Anything reachable through the public portal must be safe for anonymous callers.
- 2026-10-04: The Vercel CLI uploads the root `.env` unless `.vercelignore` lists it; its built-in ignores only cover `.env.local` files. `.vercelignore` now has `.env` and `.env.*`.
- 2026-10-04: `vercel link` appends `.vercel` and `.env*` to `.gitignore`, and `.env*` re-ignores `.env.example`. Remove those lines after linking.
- 2026-10-04: Under Vercel Services every `/api/*` request goes to the payments API, so a Next.js route handler under `frontend/app/api/` would never be reached in production. Put portal routes elsewhere (the detector key route is `/detector/sessions`).
- 2026-10-04: The `create_session` path fix is live on Compute, `DETECTOR_KEY` was rotated, and the first Vercel project (team back2back, which held the old key and served the open route) is deleted.
- 2026-10-04: streamlink downloads YouTube recordings faster than real time (a 50-minute video arrived in 15 s), and `url_source.py` doesn't pace URL input, so the scouts would drop most of a recording's clips. That's why the onboarding search returns live streams only.
- 2026-10-04: Twitch's GraphQL API (`gql.twitch.tv`, the public web Client-ID that streamlink uses) answers raw queries without a key: `searchStreams(userQuery:)` and `game(name:) { streams }`. `searchStreams` also matches channel names (gatorade2008), so the search keeps only titles that say the brand. A YouTube live search for a category ("Sports") returns news channels, so YouTube is searched by brand name only.
- 2026-10-04: Twitch embeds autoplay only when Chrome's visibility check (IntersectionObserver v2) passes: nothing on top of the player, no `backdrop-filter` (`glass`) on an ancestor, no `overflow: hidden` or border-radius clipping it (the tile's fractional width counts as clipped), and no neighbour's drop shadow reaching over it (the agent feed's shadow covered the right tile column). The console says "Autoplay disabled ... style visibility". Twitch's JS API `play()` is refused the same way, and players below the fold start when scrolled into view. That's why live Twitch tiles keep their labels under the video. Covering the player also breaks Twitch's embed rules.
- 2026-10-04: Ended live streams are replaced by the portal (`ReplaceEndedStreams`), not the detector, because the search lives in Next and a detector redeploy was on hold. So nothing happens while no sidebar page is open; the detector keeps ended sessions and replays them on WebSocket connect, so the next tab that opens catches up. Only `stream ended` and `stream offline` count: errors and finished demo files stay on the dashboard, so a broken pipeline can't loop through searches.
- 2026-10-04: The Management API's `POST https://api.supabase.com/v1/projects/pvoesovsparqqzosgwki/database/query` with the `sbp_` token in `.env` runs SQL on the hosted project, though the MCP can't. `20261004000000_brand_brief.sql` was applied that way, so like the others it isn't in the hosted migration history.
- 2026-10-04: Exa `/search` with `type: "deep-lite"` and an `outputSchema` returns structured JSON in about 5 s for 1.2¢. The schema allows at most 10 properties and nesting depth 2, which is why the brand agent makes two calls.
- 2026-10-04: Exa suggests Twitch categories that don't exist ("Travel" for "Travel & Outdoors"). Twitch's `game(name:)` is exact and returns null for them; `searchCategories` is fuzzy but maps "Travel" to "IRL" and "Esports" to a game. So the brand agent keeps exact matches only.
- 2026-10-04: Exa suggests Just Chatting and IRL for almost any brand, and the stream search ranks fit categories by viewers, so those two brought the biggest unrelated streamers (hasanabi, lacy). The brand agent drops them; Gatorade's search now lands on Sports, Food & Drink and Fitness streams of 100 to 350 viewers.
